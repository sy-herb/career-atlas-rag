# Career Atlas

### 🔎 RAG 기반 직업·직무 탐색 서비스

## 📌 프로젝트 소개

**Career Atlas**는 사용자가 다양한 직업과 직무 정보를 탐색하고 비교할 수 있도록 지원하는 RAG(Retrieval-Augmented Generation) 기반 AI 서비스입니다.

직업별 주요 업무, 필요 역량 및 관련 정보를 수집하고, 사용자의 자연어 질문에 대해 신뢰할 수 있는 자료를 검색하여 근거와 함께 답변하는 서비스를 목표로 합니다.

본 프로젝트는 **개인 포트폴리오 제작 및 AI·백엔드 기술 학습을 목적으로 진행하는 비상업적 프로젝트**입니다.

## 🎯 프로젝트 목표

- 직업·직무 메타데이터 100건 이상 확보
- 커리어넷 직업백과 Open API를 활용한 데이터 수집
- 외부 문서 수집 및 벡터 데이터베이스 색인
- 자연어 기반 직업·직무 탐색
- 검색된 문서를 활용한 근거 기반 답변 생성
- 직업별 주요 업무 및 필요 역량 비교
- 답변에 사용된 정보의 출처 제공

## ✨ 주요 기능 (개발 예정)

| 기능 | 설명 |
|---|---|
| 직업 탐색 | 자연어 조건에 맞는 직업 검색 |
| 직업 상세 조회 | 주요 업무 및 관련 역량 확인 |
| 직업 비교 | 두 직업의 업무와 역량 차이 비교 |
| AI 질의응답 | RAG 기반 직업 관련 질문 응답 |
| 근거 확인 | 답변에 활용한 문서와 원문 출처 표시 |

## 🛠 기술 스택 (예정)

| 구분 | 기술 |
|---|---|
| Language | Python |
| UI | Streamlit |
| RAG | LangChain, LangGraph |
| Vector DB | ChromaDB |
| Data API | CareerNet Open API |
| LLM | OpenAI API |

## 📂 데이터 활용 계획

- **활용 목적:** 직업 탐색 및 근거 기반 AI 질의응답
- **이용 범위:** 개인 학습 및 비상업적 포트폴리오
- **데이터 관리:** 출처 및 이용 조건 준수, API 인증키 별도 관리
